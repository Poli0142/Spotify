&#x20;<h1>Spring Microservices Project</h1>



<p>Проект представляет собой систему потокового воспроизведения музыки, построенную на основе микросервисной архитектуры с использованием Spring Boot.</p>



<h2>О проекте</h2>



<p>Система разделена на отдельные микросервисы, каждый из которых отвечает за определённую часть функциональности приложения. Такой подход упрощает разработку, сопровождение и масштабирование системы.</p>



<h2>Архитектура проекта</h2>



<ul>

&#x20; <li><b>api-gateway</b> — единая точка входа для запросов к сервисам.</li>

&#x20; <li><b>config-server</b> — централизованное управление конфигурациями.</li>

&#x20; <li><b>eureka-server</b> — регистрация и обнаружение микросервисов.</li>

&#x20; <li><b>user-service</b> — сервис работы с пользователями.</li>

&#x20; <li><b>catalog-service</b> — сервис музыкального каталога.</li>

&#x20; <li><b>playlist-service</b> — сервис плейлистов.</li>

&#x20; <li><b>streaming-service</b> — сервис потокового воспроизведения.</li>

&#x20; <li><b>database</b> — каталог, связанный с базой данных проекта.</li>

</ul>



<h2>Основные технологии</h2>



<ul>

&#x20; <li>Java</li>

&#x20; <li>Spring Boot</li>

&#x20; <li>Spring Cloud Config</li>

&#x20; <li>Netflix Eureka</li>

&#x20; <li>Spring Cloud Gateway</li>

&#x20; <li>Maven</li>

&#x20; <li>Swagger / OpenAPI — если настроен в проекте</li>

</ul>



<h2>Запуск проекта</h2>



<p>Для запуска необходимы установленная Java и настроенная среда выполнения проекта.</p>



<ol>

&#x20; <li>Склонируйте репозиторий на компьютер.</li>

&#x20; <li>Откройте командную строку в корневой папке проекта.</li>

&#x20; <li>Запустите файл <code>start-all.bat</code> либо используйте инструкции для отдельных сервисов.</li>

</ol>



<h2>Структура проекта</h2>



<p>В корневой папке находятся Maven-файл <code>pom.xml</code>, скрипты запуска, а также каталоги отдельных микросервисов.</p>
